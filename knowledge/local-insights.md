# Local Insights Search Framework (人)

## Search Query Templates

### Scams & Pitfalls
| Query | Purpose |
|-------|---------|
| `"{dest} 骗局 坑人 套路"` | Common scams |
| `"{dest} 注意事项 避坑"` | General warnings |
| `"{dest} 宰客 乱收费"` | Overcharging traps |
| `"{dest} 黑车 黑导游"` | Illegal services |

### Weather & Timing
| Query | Purpose |
|-------|---------|
| `"{dest} [月份] 天气 穿什么"` | Weather + clothing |
| `"{dest} 最佳旅游时间"` | Best season to visit |
| `"{dest} 雨季 台风 影响"` | Weather hazards |
| `"{dest} [节日] 活动 [年份]"` | Festival/event dates — use current year |

### Culture & Customs
| Query | Purpose |
|-------|---------|
| `"{dest} 当地风俗 禁忌"` | Cultural taboos |
| `"{dest} 方言 沟通"` | Language barriers |
| `"{dest} 赶集 庙会 时间"` | Local market days |

### Output Format
Three categories:
1. **⚠️ 避坑清单:** Common scams, overcharging tactics, fake guides, with specific red flags to watch for
2. **🌤 天气穿搭:** Forecast-based clothing advice, rain gear needs
3. **📅 节庆活动:** Any festivals/markets during the travel dates, with verification of current year dates

### Key Rules
1. Scam information is the most important part — an otherwise perfect trip can be ruined by one scam
2. Weather must be date-specific, not generic "summer is hot"
3. Festival dates must be confirmed for the current year — lunar calendar conversions are tricky
4. Always include emergency numbers: police 110, ambulance 120, local tourist complaint hotline
