# Travel Guide

A travel planning Claude Code skill that produces customized, source-verified itineraries. Never guesses about a destination — always searches, verifies, and labels confidence.

## Why This Skill Exists

直接用 Claude 问"帮我规划一个XX旅行"也能得到回答，但它会**编造信息**——虚构不存在的餐厅、过时的票价、甚至已经关门的景点。大模型的知识有截止日期，而旅行信息（价格、开放时间、季节景观）变化极快。

This skill 强制 Claude 做它本来不会做的事：

- **先确认需求，再动手** — 不会上来就给你一个没人想要的行程。先出确认卡，你点头了才开始搜。
- **5 维度并行搜索** — 交通、美食、景点、住宿、避坑同时搜，不是凭记忆编。每个数据点标注可信度（✅⚠️⚡❓），信息从哪来的你一清二楚。
- **地理路线优化** — 不会让你 Day 1 经过景点 A 不进去、Day 3 又开 200km 折返。行程按地图顺序排列，不走回头路。
- **预算透明到每一笔** — 机票、住宿、门票、吃饭全列出来，和你的预算对比，超没超一目了然。
- **避坑 + 备选 + 抢票提醒** — 目的地的常见骗局、下雨怎么办、莫高窟门票提前 30 天抢——这些纯 prompt 根本不会系统性地帮你查。

简单说：**纯 prompt = 一个学过旅行知识但记忆停留在 6 个月前的朋友。这个 skill = 一个会先问清楚你需求、然后上网帮你搜索验证、最后给出真实可执行方案的旅行规划师。**

## How It Works

The skill follows a strict **three-phase flow**:

**Phase 1: Confirm (确认)** — 解析你的需求，找出缺失信息，输出确认卡。你不点头，它不瞎搜。

**Phase 2: Research (调查)** — 5 维度并行 WebSearch：交通（行）、美食（食）、景点（游）、住宿（住）、本地洞察（人）。每个数据交叉验证，标注可信度。

**Phase 3: Report (报告)** — 输出完整旅行计划：基本信息 → 路线逻辑 → 每日行程 → 预算明细 → 避坑清单 → 备选方案 → 实用信息。

### ⚠️ 避坑指南

系统性地搜索目的地的常见骗局和陷阱，每条标注来源：

- **低价团陷阱** — 低于¥4,000/人的7-8天团，63% 存在强制购物、中途加价（来源：青海文旅投诉数据 2025）
- **"免费拍照"套路** — 景区门口免费拍，之后索要 ¥50-100 打印费
- **茶卡盐湖赤脚下水** — 卤水有腐蚀性，必须穿鞋套

### 🔔 关键抢票提醒

- 🔴 **莫高窟 A 类票必须提前 30 天在小程序抢！** 每天限 6000 人。这是整趟旅行最可能翻车的地方，skill 会反复强调。

### 🔄 备选方案

计划赶不上变化，skill 帮你想到各种意外：

- **下雨？** 盐湖不出片→改塔尔寺深度游；七彩丹霞雨后反而颜色最艳
- **莫高窟没票？** 应急票¥100/4个窟，或看《又见敦煌》沉浸演出 ¥298
- **高反严重？** 青海段缩短，尽快下到敦煌（海拔仅 1139m），备葡萄糖口服液

### 📱 实用信息

- 紧急电话、青海/甘肃旅游投诉热线
- 洋葱式穿搭指南（内层短袖→中层卫衣→外层冲锋衣）
- SPF50+ 防晒霜、墨镜、润唇膏
- 提前下载甘肃+青海离线地图（多路段无信号）
