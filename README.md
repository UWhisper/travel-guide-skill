# Travel Guide（旅行规划助手）

一个基于搜索验证、而非凭记忆编造的 Claude Code 旅行规划技能。绝不瞎猜目的地信息 —— 始终先搜索、再交叉验证、最后标注可信度。

## 为什么需要这个技能？

直接问 Claude"帮我规划一个XX旅行"也能得到回答，但它会**编造信息**——虚构不存在的餐厅、过时的票价、甚至已经关门的景点。大模型的知识有截止日期，而旅行信息（价格、开放时间、季节景观）变化极快。

这个技能强制 Claude 做它本来不会做的事：

- **先确认需求，再动手** — 不会上来就给你一个没人想要的行程。先出确认卡，你点头了才开始全网搜索。
- **五个维度并行搜索** — 交通、美食、景点、住宿、避坑同时查，不是凭记忆编。每个数据点标注可信度（✅⚠️⚡❓），信息来源一清二楚。
- **地理路线优化** — 不会让你第一天经过景点不进去、第三天又开两百公里折返。行程按地图顺序排列，不走回头路。
- **预算透明到每一笔** — 机票、住宿、门票、吃饭全列出来，和你的预算做对比，超没超一目了然。
- **避坑 + 备选 + 抢票提醒** — 目的地的常见骗局、下雨怎么办、莫高窟门票提前三十天抢——这些纯提示词根本不会系统性地帮你查。

简单说：**纯提示词 = 一个学过旅行知识但记忆停留在半年前的朋友。这个技能 = 一个会先问清楚你需求、然后上网帮你搜索验证、最后给出真实可执行方案的旅行规划师。**

## 用户使用流程

整个过程分为三个阶段，环环相扣，不允许跳过：

**第一阶段：确认需求** — 你只需要说"我想去XX玩"，技能会自动解析你的需求，找出缺失的信息（日期？预算？几个人？喜欢自然还是人文？），输出一张确认卡。你不回"OK"，它不开始搜。

**第二阶段：全网搜索** — 收到确认后，从五个维度同时启动搜索：交通怎么去、有什么好吃的、哪些景点值得去、住哪里方便安全、当地有什么坑要避开。所有信息交叉验证，标注可信度。

**第三阶段：输出方案** — 根据你的偏好（节奏快慢、预算高低、是否带小孩/长辈），输出一份包含每日时间安排、预算明细、避坑清单、备选方案、实用贴士的完整旅行计划。

## 输出案例展示

下面以 [`Examples/青甘大环线9天旅行计划.md`](Examples/青甘大环线9天旅行计划.md) 为例，展示技能的实际输出能力。场景：杭州出发，情侣双人，青甘大环线九天八晚。

### 📋 需求确认

技能首先输出确认卡，确保每个细节都对齐：

| 项目 | 内容 |
|------|------|
| 目的地 | 青甘大环线（青海→甘肃） |
| 日期 | 2026年5月23日 → 5月31日，八晚九天 |
| 预算 | 人均 ¥5,000–8,000（含往返机票） |
| 人员 | 情侣双人 |
| 偏好 | 自然风光 + 人文历史，节奏正常偏轻松 |

### 🗺️ 每日时间与路线规划

行程**按地理位置优化**，顺时针环线不走回头路。每天精确到上午/中午/下午/晚上四个时段，每个项目标注耗时、交通方式、费用、可信度：

```
第一天： 杭州 ✈ 西宁 → 酒店休整适应 → 莫家街夜市
第二天： 西宁 → 塔尔寺(西南30公里) → 青海湖黑马河 → 茶卡镇
第三天： 茶卡盐湖(晨) → 德令哈 → 大柴旦翡翠湖 → 大柴旦镇
第四天： 大柴旦 → 当金山 → 阿克塞 → 敦煌
第五天： 敦煌全天（莫高窟→午休→鸣沙山月牙泉→沙洲夜市）
第六天： 敦煌 → 嘉峪关 → 张掖
第七天： 七彩丹霞(晨) → 扁都口 → 祁连卓尔山
第八天： 祁连草原 → 门源 → 达坂山 → 西宁
第九天： 西宁 ✈ 杭州
```

以第五天（敦煌）为例，每个活动都有具体时间和花费：

| 时段 | 项目 | 详情 | 费用 |
|------|------|------|------|
| 上午 | 莫高窟 | A类票 ¥238，八个窟加数字电影，约三小时 | ¥238/人 |
| 中午 | 酒店午休 | 敦煌正午三十多度，回酒店避开高温 | ¥30–50 |
| 下午 | 鸣沙山月牙泉 | 下午五点后入园，沙子不烫，骑骆驼 ¥100 | ¥110 |
| 晚上 | 星空演唱会 | 免费露天演唱会，约晚上九点 | ¥0 |

### 💰 两种预算方案对比

技能不是给你一个模糊的"大概多少钱"，而是给出**可选的两种方案**，每项费用都列清楚：

| 类别 | 方案一：拼车小团 | 方案二：双人包车 |
|------|-----------------|-----------------|
| 往返机票 | ¥1,500–1,800 | ¥1,500–1,800 |
| 交通（七天） | ¥2,200–2,800 | ¥3,500–4,200 |
| 住宿（八晚） | ¥1,000–1,200 | ¥1,000–1,200 |
| 门票体验 | ¥750–850 | ¥750–850 |
| 餐饮 | ¥700–900 | ¥700–900 |
| **人均总计** | **¥6,450–7,550** ✅ | **¥7,750–9,250** ⚠️ |

### ⚠️ 避坑指南

系统性地搜索目的地的常见骗局和陷阱，每条标注来源：

- **低价团陷阱** — 低于 ¥4,000/人的七八天团，超过六成存在强制购物、中途加价（来源：青海文旅投诉数据 2025）
- **"免费拍照"套路** — 景区门口免费拍，之后索要 ¥50–100 的高价打印费
- **茶卡盐湖赤脚下水** — 卤水有腐蚀性，必须穿鞋套

### 🔔 关键抢票提醒

- 🔴 **莫高窟 A 类票必须提前三十天在小程序抢！** 每天限六千张。这是整趟旅行最可能翻车的地方，技能会反复强调。

### 🔄 备选方案

计划赶不上变化，技能帮你想到各种意外：

- **下雨？** 盐湖不出片→改塔尔寺深度游；七彩丹霞雨后反而颜色最艳
- **莫高窟没票？** 应急票 ¥100/四个窟，或看《又见敦煌》沉浸演出 ¥298
- **高反严重？** 青海段缩短，尽快下到敦煌（海拔仅 1139 米），备葡萄糖口服液

### 📱 实用信息

- 紧急电话、青海/甘肃旅游投诉热线
- 洋葱式穿搭指南（内层短袖→中层卫衣→外层冲锋衣）
- SPF50+ 防晒霜、墨镜、润唇膏
- 提前下载甘肃加青海离线地图（多路段无信号）

## 安装使用

1. 将此技能安装到你的 Claude Code 技能目录中
2. 通过询问旅行规划、行程推荐、目的地攻略来触发
3. 技能会自动引导你完成需求确认，然后开始搜索和规划

## 生成方式

此技能通过 [domain-distiller](https://github.com/UWhisper/domain-distiller) 生成 —— 一个将领域知识蒸馏为结构化、可用于决策的 Claude Code 技能的工具。Domain-distiller 将分散的专业知识（博客、攻略、清单、个人经验）转化为严谨的技能格式，包含强制阶段、验证规则和输出模板。
